One original fortune-cookie line for a software developer for make.fun's "Fortune Cookie Wisdom for Developers" bounty — a single sentence of 82 characters, written to `$MAKEFUN_OUTPUT_DIR/entry.txt` by `main.ts` (Node 22, stdlib only, fully deterministic):

> The code you write in a hurry will be read slowly, by someone who knows your name.

The line is built on the judge's brief: a tired senior engineer picks the line that makes it smile and nod. It is a fortune-cookie line, not a slogan or generic advice; one short balanced sentence (hurry/slowly, write/read) that lands in a single breath; true about a developer's day (rushed code gets read in review, in an incident, by the next person to touch it); a fresh turn (the hurry is yours, the slowness is theirs); and a quiet twist that rewards a second read ("someone who knows your name" — the reader is not a stranger, they know exactly whose code this is).
